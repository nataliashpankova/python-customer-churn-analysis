# 📊 Customer Churn Analysis using Python

## 📌 Objective
Analyze customer data to identify factors influencing churn and provide actionable business insights to improve customer retention.

## 📊 Dataset
Customer dataset including:
- Demographics (age, gender)
- Subscription details (contract type, tenure)
- Financial data (monthly charges, total charges)
- Target variable: churn (Yes/No)

## 🔧 Tools
- Python (pandas, matplotlib, seaborn)
- Jupyter Notebook

## 🔍 Analysis
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Customer churn distribution
- Behavioral analysis (charges, tenure)
- Correlation analysis between features
- Visual storytelling with charts

## 📈 Key Insights
- Customers with monthly contracts show higher churn rates
- Higher monthly charges correlate with increased churn
- Customers with shorter tenure are more likely to leave

## 💡 Business Recommendations
- Offer incentives for long-term contracts
- Target high-risk customers with retention campaigns
- Optimize pricing strategies for high-charge segments
